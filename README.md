# 极简麻雀 - 需求梳理文档

## 一、产品定位

**极简麻雀** 是一款基于云同步的个人物品管理工具，帮助用户记录、追踪和盘点个人物品。

### 核心价值
- **极简操作**：3秒完成物品录入
- **云端同步**：多设备数据自动同步
- **私密安全**：数据归属个人账号

---

## 二、用户画像

| 用户类型 | 特征 | 核心需求 |
|---------|------|---------|
| 极简主义者 | 追求精简生活，需要盘点物品 | 掌握物品总量，定期清理 |
| 整理控 | 喜欢分类收纳 | 分类管理，快速查找 |
| 普通用户 | 记性不好，常忘记东西放哪 | 记录位置，避免重复购买 |
| 搬家党 | 需要统计所有家当 | 导出清单，物品盘点 |

## 三、功能需求

### 3.1 MVP版本（第一版）

#### F-01 用户登录
- 手机号/邮箱注册登录
- 一键匿名体验（可选）

#### F-02 物品列表
- 瀑布流/列表式展示
- 显示：图片、名称、分类、添加时间
- 支持按时间/分类排序
- 支持关键词搜索

#### F-03 添加物品
- 必填：物品名称
- 可选：分类、备注、图片（1张）
- 扫码添加（条形码/二维码）- 预留

#### F-04 编辑物品
- 修改所有字段
- 删除物品

#### F-05 物品详情
- 完整信息展示
- 大图预览

#### F-06 统计概览
- 物品总数
- 各分类数量及占比
- 最近添加的物品

#### F-07 数据同步
- 登录后自动同步云端
- 离线操作，联网后同步

## 五、非功能需求

### 5.1 性能要求

| 指标 | 目标 |
|------|------|
| 首屏加载 | < 1.5秒 |
| 物品列表滚动 | 60fps |
| 图片上传 | 压缩后 ≤ 2MB |
| 云函数响应 | < 500ms |
| 离线操作 | 支持（联网后同步） |

### 5.2 安全要求
- 用户数据隔离（多用户互不可见）
- 图片存储权限隔离
- 登录态有效期管理

### 5.3 兼容性
- iOS 12+
- Android 8+
- 微信小程序
- H5

### 5.4 设计原则
- **极简视觉**：黑白灰为主，无冗余装饰
- **一致交互**：统一的操作反馈和动画
- **无干扰**：无广告、无推送

## 七、页面结构

```
启动页（可选）
    ↓
登录/注册页 ←→ 匿名体验入口
    ↓
┌─────────────────────────────┐
│         首页（物品列表）       │
│  - 统计卡片（总数）           │
│  - 搜索/筛选                 │
│  - 物品列表（无限滚动）        │
│  - 悬浮添加按钮              │
└─────────────────────────────┘
    ↓                        ↓
添加/编辑页              统计页
- 表单填写              - 总数卡片
- 图片上传              - 分类分布
- 保存/删除             - 趋势图（后期）
                              ↓
                         详情页（从列表进入）
```

## 八、业务流程

### 8.1 用户首次使用流程

```
下载App → 选择登录/匿名体验 → 进入首页 → 点击+添加第一件物品 → 填写信息 → 保存 → 看到物品在列表中
```

### 8.2 日常使用流程

```
打开App → 查看物品列表 → 搜索/筛选找到物品 → 查看详情/编辑/删除
```

### 8.3 数据同步流程

```
用户操作 → 本地先更新UI → 异步请求云端 → 成功 → 更新本地状态
                            ↓
                          失败 → 提示重试
```

## 九、约束与假设

### 技术约束
- 使用 uni-app + uniCloud 开发
- 数据库使用 MongoDB（阿里云/Tencent云）
- 图片存储在 uniCloud 云存储

### 业务假设
- 初期用户量 < 1000
- 单用户物品数量 < 500件
- 单张图片 < 2MB

### 时间约束
- MVP开发：2周
- 测试修复：3天
- 提审上架：3-7天

## 十、风险与应对

| 风险 | 概率 | 影响 | 应对措施 |
|------|------|------|---------|
| 云函数调用超限 | 低 | 中 | 设置合理QPS，前端做请求节流 |
| 图片存储成本过高 | 中 | 中 | 限制单张大小，定期清理未引用图片 |
| 用户数据丢失 | 低 | 高 | 提供数据导出，定期提醒备份 |
| 登录态失效频繁 | 中 | 低 | 合理设置token有效期，自动续期 |
